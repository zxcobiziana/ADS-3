For this assignment I worked with three algorithms: Bubble Sort, Quick Sort, and Binary Search. My goal was to see how they behave on arrays of different sizes and conditions, and then compare the actual execution times with what we expect from Big‑O complexity.

I set up the program so it generates arrays, sorts them using Bubble Sort and Quick Sort, and then applies Binary Search once the data is sorted. To make the comparison fair, I measured the execution time with System.nanoTime().
